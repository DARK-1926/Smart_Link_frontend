# 🚀 Smart Link Hub | Frontend

The frontend of **Smart Link Hub** is a high-performance, interactive dashboard built to transform static link lists into a dynamic "Smart Career Concierge." It utilizes a high-contrast **Black & Green** aesthetic, adhering to strict design requirements while providing a personalized experience for every visitor.

## ✨ Core Innovation: "Who Are You?"
Unlike traditional link aggregators, this frontend features an **Active Intent Splash Screen**. 
* **Intent Capture:** Visitors are greeted with a "Who are you?" prompt (Recruiter, Peer, or Student).
* **Dynamic Reflow:** Based on the selection, the UI triggers a backend request to re-prioritize and highlight specific links (e.g., Resumes for Recruiters, Repos for Peers).
* **Auto-Promotion:** Real-time visual badges like "🔥 Trending" are applied to links with the highest click-through rates.

## 🎨 UI Styles & Visuals
The project supports 5 distinct design "Personalities" that can be toggled to match the creator's brand:

| Style | Key Visual Elements | Interaction Detail |
| :--- | :--- | :--- |
| **Liquid Glass** | Refractive blurs, "wet" gloss | Water droplet ripple on hover |
| **Glassmorphism** | Multi-layered frosted panels | Z-axis parallax on mouse move |
| **Claymorphism** | Matte, inflated 3D surfaces | Bouncy, squishy click animations |
| **Neo-Brutalism** | Hard shadows, 4px borders | 45° Isometric "pop" on hover |
| **Skeuomorphism** | Brushed metal, carbon fiber | Tactile 3D button press depth |

## 🛠 Tech Stack
* **Framework:** React.js / Vite (Optimized for 2026 standards)
* **Styling:** Tailwind CSS + Framer Motion (for fluid liquid animations)
* **State:** Context API for Persona Management
* **Icons:** Lucide-React (Customized with Neon Green strokes)
